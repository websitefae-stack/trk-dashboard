Admin tools for Frappe LMS courses - not tied to onboarding, use these any time you're setting up a course.

Share an Existing Module With Another Course

Picks an existing chapter (with all its lessons) into a second course too - nothing is copied, so editing the lesson still only ever needs doing in one place. Works for any two courses - set up the destination course in LMS first (it can be empty, with no chapters of its own yet).
