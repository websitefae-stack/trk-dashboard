Import Schools

A CSV file, one row per contact: School Name, Website (optional), Area (optional), Contact Name, Contact Role (SENCO, Head, Deputy Head, Reception or Other - optional), Contact Email. Several contacts for the same school are just several rows with the same School Name. If a school already exists (matched by name), new contacts are added to it rather than creating a duplicate - already-imported contacts are skipped, so it's safe to re-upload the same file after fixing a few rows.
