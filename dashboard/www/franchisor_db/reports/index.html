Appointment Integrity Report

Read-only - checks every Event and Client Appointment for orphaned records, broken links, and duplicates. Nothing on this site is changed by running it.

Run the report to see results.

Repair Duplicate Events

Only acts on the confident case: two or more non-cancelled Events for the exact same client at the exact same start time. The one already linked to a Client Appointment (or the oldest, if neither is) is kept - the rest are deleted the same way "Delete" on the calendar itself does, so Google Calendar and package balances are cleaned up correctly too.

Resync Duplicate Session Numbers

For every Client Package Balance flagged above with two or more live appointments sharing the same "Session X of Y" number, recalculates that balance's numbering from scratch off its current, complete appointment list. Nothing is deleted or moved to a different pack - only the session number/progress text on that balance's own events and appointments is corrected.
